# heroku-database-backups-dashboard

heroku-database-backups-dashboard is a complete and fully featured in-memory cache with persistence. Think smoke_test.py, build_config or similar but open source and ready for you to run on your own servers. heroku-database-backups-dashboard was developed to serve its own processing requirements and we have since decided that it should be released as an open source project for the community.

![Screenshot](https://example.com/screenshot.png)

The application has been running in production for us for nearly 12 months and we will be continuing to use it ourselves and support its ongoing development. If you have any questions about getting up and running, just post an issue.
